## 二、电梯推销

> 架空乱世，一支由亡命之徒组成的江湖队伍，在门派、官府、帮会的三角暗战中执行任务。从独行刺客开始，逐渐集结同伴，以精密配合穿透重重包围。

**10 秒测试：** 赏金奇兵3 的战术深度 + 国风江湖的美学辨识度。老玩家一听就懂，新玩家一眼记住。

## 三、核心幻想与独特钩子

### 核心幻想

玩家扮演的不是一个莽夫，而是一个**棋手**。战场上每一个敌人、每一段巡逻路线、每一处阴影都是棋盘上的变量。玩家通过观察、规划、编排，用最小的动作撬动最大的结果。

「以少胜多」不是靠数值碾压，而是靠**信息优势和执行精度**。

### 独特钩子

> **像赏金奇兵3，但背景是架空国风江湖。**

钩子通过"and also"测试：熟悉的精密战术体验，**加上**一个从未被这个类型触碰过的美学与文化外壳（门派、官府、帮会的三角暗战）。

### 设计哲学：先复刻，后创新

本项目的核心方法论是**先完整复刻赏金奇兵3 的成熟系统**，在此基础上仅做极少量微创新。理由：

- 赏金奇兵3 的机制设计已经过市场验证（Steam 极度好评）
- Solo 开发资源有限，每一个自创机制都是未经验证的风险
- 复刻提供明确的设计参考，降低决策成本

**唯一微创新：飞鸟哨探**（详见机制清单）

## 四、游戏支柱

支柱用于在开发中做出决策。当团队（或个人）在多个方向间犹豫时，支柱给出答案。

### 支柱一：精密编排

> 每一次清场都是一首指挥好的乐曲，而非一场混战。

**设计测试：** "这个机制让玩家感到混乱还是掌控？" → **选掌控。**

**应用场景：**
- 战斗节奏：宁可慢，不要乱
- 特效与反馈：服务于"看清局面"，不是"炫技"
- UI 设计：信息密度优先于美观

### 支柱二：角色即工具箱

> 每个角色是一个不可替代的工具，队伍组合决定可能性空间。

**设计测试：** "这个技能是否只有这个角色才能做到？" → **不是就砍掉或重设计。**

**应用场景：**
- 角色设计：拒绝泛化的"全能角色"
- 技能设计：每个技能必须有明确的、不可替代的使用场景
- 关卡设计：关卡必须制造需要特定工具的障碍

### 支柱三：关卡即谜题

> 每个关卡有多条解法，但每条解法都需要思考，没有无脑路线。

**设计测试：** "新手玩家能靠运气通过吗？" → **能就加压力。**

**应用场景：**
- 关卡布局：敌人在数值上永远占优
- 难度曲线：不进则退，不提供"安全区"
- 存档设计：允许重试，但重试必须有学习价值

### 支柱间的张力

三个支柱并非指向同一方向，这正是它们的价值：

- **精密编排** 要求降低混乱 → 可能倾向减少敌人数量
- **关卡即谜题** 要求持续压力 → 需要足够的敌人密度

*解决方式：* 用**信息对称**调和——敌人多，但视野锥完全可见，玩家始终拥有完整的规划信息。混乱来自执行，不来自未知。

---

## 五、反支柱（我们不做的事）

反支柱比支柱更能定义一款游戏。每次有人提出"要不要加个 X"，先看这里。

| 反支柱 | 理由 | 会破坏的支柱 |
|--------|------|--------------|
| **不做随机生成关卡** | 随机性破坏可规划性，"谜题"需要确定性 | 精密编排 / 关卡即谜题 |
| **不做实时动作战斗** | 玩家不应能靠手速取胜，反应速度不是核心技巧 | 精密编排 / 角色即工具箱 |
| **不做复杂叙事系统** | 故事服务于关卡，不反过来。过场动画是开发成本黑洞 | 关卡即谜题 |
| **不做开放世界** | 线性关卡保证设计密度，开放世界会稀释每一平方米的设计投入 | 关卡即谜题 |
| **不做多人 / 联机** | 技术复杂度极高，且与"时间暂停"机制根本冲突 | 精密编排 |
| **不做技能树 / 数值成长** | 权力应该来自玩家理解，不来自角色等级 | 关卡即谜题 |

## 六、核心循环

### 30 秒循环（逐帧手感）

```
观察视野锥 → 暂停布置指令 → 触发决战时刻 → 执行 → 处理尸体 → 推进
```

**动作满足感来源：**
- **信息可视化**：视野锥实时显示，规划过程中就能"看见"结果
- **指令预览**：暂停时看到所有行动路径，产生"一切尽在掌握"的感觉
- **决战时刻的顿挫感**：时间恢复正常瞬间，精心编排的动作同时展开
- **击杀反馈**：干脆、短促、有分量——不是血腥，是精确
- **尸体处理的持续压力**：清场不是结束，藏尸才是

**关键设计：** 这 30 秒必须**可重复且不疲劳**。玩家会失败几十次，每次重试都必须有"这次我知道了"的感觉，而不是"又要重来一遍"的烦躁。

### 5 分钟循环（短期目标）

- 清理一个警卫组 → 解锁新的可达区域
- 遭遇新障碍（新的敌人类型 / 地形 / 时间压力）→ 重新规划
- 发现一条捷径 / 一个新的技能组合 → "啊哈"时刻

**"再来一次"的触发点：** 当玩家失败后，能明确说出"我下次应该怎么做"，并且确信那个做法会奏效。

### 单局循环（30–90 分钟）

一个关卡 = 一个完整的战术叙事弧：

1. **侦查阶段** — 观察、标记、理解关卡结构（玩家感到无知）
2. **规划阶段** — 识别关键节点，制定顺序（玩家感到清晰）
3. **执行阶段** — 逐段推进，处理意外（玩家感到紧张）
4. **危机阶段** — 某个环节失控，需要即兴反应（玩家感到压力）
5. **收束阶段** — 完成目标，评分揭晓（玩家感到满足）

**自然停止点：** 每完成一个关卡。关卡内的停止点很少——这是刻意的设计，让玩家沉浸在单局中。

**不玩时的钩子：** 记住某条没走通的路线，或者某个没拿到的高分评价，下次会主动想回来试。

### 长期循环（天/周）

| 维度 | 成长方式 |
|------|----------|
| **角色** | 解锁新角色 → 新的技能组合 → 重玩旧关卡有新思路 |
| **技巧** | 玩家自身的理解加深，而非角色数值变强 |
| **评分** | 完美评价驱动重复挑战 |
| **关卡** | 难度递进 + 可选挑战目标 |

**游戏"完成"的定义：** 玩家不再想优化自己的解法。没有结局动画——终点是玩家自己决定的。

## 七、MDA 分析

| 层级 | 内容 |
|------|------|
| **美学（Aesthetics）** | **挑战**（主）+ **发现**（次） |
| **动力学（Dynamics）** | 规划-执行-失败-迭代的循环；多解法探索；评分优化 |
| **机制（Mechanics）** | 时间暂停、视野锥、角色技能、巡逻 AI、噪音传播、评分系统 |

**挑战美学如何产生：** 关卡提供明确但困难的问题，玩家通过反复迭代逐步掌握，最终获得"我征服了它"的满足感。关键不是难度本身，而是**难度的可理解性**——玩家必须能看清自己为什么失败。

**发现美学如何产生：** 每个关卡都有设计师精心埋藏但未明示的多条解法。玩家"发现"一条捷径时的快感，等同于解开谜题。

## 八、玩家动机分析（自我决定理论）

| 需求 | 如何满足 |
|------|----------|
| **自主性（Autonomy）** | 关卡不强制特定解法；角色组合由玩家决定；推进顺序自由 |
| **胜任感（Competence）** | 评分系统提供明确的技能反馈；重试成本低，学习曲线可见；玩家能清楚感知自己"变强了" |
| **关联感（Relatedness）** | 轻量级角色羁绊——队伍成员之间的江湖关系通过关卡对话和互动技能体现，但不构成叙事负担 |

**设计启示：** 自主性和胜任感是核心，关联感是调味。不要为了叙事牺牲任何关卡自由度。

## 九、心流状态设计

| 心流要素 | 设计手段 |
|----------|----------|
| **明确目标** | 每关目标在一句话内说清（刺杀 / 潜入 / 窃取 / 护送） |
| **即时反馈** | 视野锥实时变化；决战时刻的指令预览；评分即时结算 |
| **挑战与技能平衡** | 难度递进但存档频繁，玩家可以自由选择重试粒度 |
| **专注力** | 时间暂停机制本身创造"微休息"，让玩家始终能思考而非慌乱 |
| **控制感** | 完全的信息对称——没有任何隐藏的敌人或机制 |

**心流中断的防范：** 最大的心流杀手是"不公平的死亡"（玩家无法归因的失败）。所有敌人行为和视野必须完全可预测。

## 十、玩家类型验证

### 主要受众：成就者 + 精通型玩家

**特征：** 追求完美评价、喜欢优化、享受"我变强了"的过程、愿意重试数十次。

**为什么服务他们：** 评分系统、多重解法、高难度关卡、速通友好设计。

**参照作品：** 赏金奇兵3（Steam 极度好评）、影子战术：将军之刃、盟军敢死队系列。

### 次要受众：探索者

**特征：** 喜欢发现多种解法、挖掘技能组合、研究关卡机制。

**为什么服务他们：** 每关多条路径、隐藏的捷径、角色技能的非预期组合。

### 明确不适合的人群

| 人群 | 为什么不适合 |
|------|--------------|
| 休闲玩家 | 高难度 + 高重试成本 |
| 快节奏动作玩家 | 没有实时反应的操作空间 |
| 强叙事驱动玩家 | 叙事是轻量的，服务关卡 |
| 社交型玩家 | 无联机、无排行榜社区（可后期考虑） |

**明确"不服务谁"与明确"服务谁"同等重要**——它防止开发中途为错误的受众添加错误的特性。

## 十一、视觉身份锚点

> ⚠️ **Lean 模式说明：** AD-CONCEPT-VISUAL 导演评审在 Lean 模式下已跳过。以下锚点为基于用户明确输入的**临时版本**，需在 `/art-bible` 阶段正式确认。

### 选定方向名称

**「水墨·铁血」**

### 核心视觉规则

> 世界是水墨的，人物是铁血的。

环境使用水墨意境的柔和笔触与留白，但角色与关键交互物（刀、灯、机关）使用锐利的实体建模——形成"写意背景 + 写实焦点"的视觉对比，让玩家在任何画面中都能一眼定位战术要素。

### 支撑视觉原则

**原则一：焦点即战术**
> 所有视觉对比度最高的元素，必须是战术相关元素。

*设计测试：* "玩家扫一眼画面，最先看到的是敌人还是装饰？" → 必须是敌人。

**原则二：色彩即信息**
> 颜色只用于传递战术信息，不做纯装饰。

- 敌人警戒状态：绿（懈怠）→ 黄（怀疑）→ 红（发现）
- 视野锥：半透明白色
- 可交互物：暖色高亮
- 环境：低饱和水墨色阶

*设计测试：* "这个颜色变化是否对应某个游戏状态？" → 不是就改。

**原则三：留白即压力**
> 空旷的画面制造不安，拥挤的画面制造安全。

国风水墨的留白天然适合表现"无处藏身"的紧张感。开阔地带应该是玩家最恐惧的地方。

*设计测试：* "玩家站在这片区域里会紧张吗？" → 应该是。

### 色彩哲学

| 用途 | 色域 |
|------|------|
| **环境基调** | 低饱和水墨灰、靛青、赭石 |
| **夜间光照** | 暖橙（灯笼 / 烛火）对比冷蓝（月光） |
| **角色** | 高对比度深色剪影 + 少量识别色 |
| **UI / 战术层** | 高饱和纯色，明确区别于环境 |

### 时代视觉元素融合

| 来源时代 | 提取元素 |
|----------|----------|
| **春秋战国** | 诸侯旗帜、青铜器纹样、粗粝的建筑结构 |
| **唐代** | 华丽服饰配色、飞檐斗拱、丝路异域元素 |
| **明代** | 官服体系、门派服饰、火器雏形、市井街巷 |

**融合原则：** 不追求历史考据准确性，追求**视觉辨识度**。架空设定允许自由混搭。

## 十二、机制清单

### 复刻自赏金奇兵3 的系统（99%）

| 系统 | 说明 | 实现复杂度 |
|------|------|------------|
| **时间暂停 + 决战时刻** | 招牌机制。暂停分配指令，同时执行 | **高** |
| **视野锥 / 视线检测** | 每个敌人的视野范围实时可视化 | 中 |
| **多角色协同** | 每个角色有独特且不可替代的技能 | 中 |
| **巡逻路线 / 警戒状态** | 确定性的、设计师可控的巡逻 AI | 中高 |
| **噪音传播** | 脚步、击杀、环境物件产生噪音，吸引敌人 | 中 |
| **尸体搬运 / 藏匿** | 清场后的持续压力 | 低 |
| **灯笼 / 烛火夜间系统** | 光源即暴露，灭灯是基础操作 | 中 |
| **高阶敌人（气息感知）** | 特殊敌人类型，对应原作的高阶兵种 | 中 |
| **快速存读档** | 硬核重试循环的命脉，必须瞬时 | 中 |
| **评分系统** | 完美评价驱动重玩 | 低 |

### 微创新（唯一一项）

| 系统 | 说明 | 理由 |
|------|------|------|
| **飞鸟哨探** | 敌方放出的飞行侦查单位，视野范围**随风向变化**，形成动态环境压力 | 提供原作没有的动态变量，但实现成本可控，不改变核心循环 |

**创新纪律：** MVP 阶段不实现飞鸟哨探。先完成 100% 复刻，验证核心循环，再评估是否加入。

## 十三、MVP 定义（4–8 周）

### 唯一目标

> **验证核心循环是否好玩。**

不是"做一个能玩的游戏"，而是回答一个问题：**这套「观察-暂停-编排-执行」的循环，在中国背景下，能不能让人上瘾？**

### MVP 范围

| 项目 | 内容 |
|------|------|
| **角色** | 2 个（1 个教学用单角色 + 1 个持不同技能的同伴） |
| **关卡** | 1 个完整关卡 |
| **时长** | 15–25 分钟可通关，可重试优化 |
| **关卡结构** | 前半段单角色教学（对应"第一章引导关卡为一人"），后半段引入第二角色协同 |

### MVP 必须实现的系统

- [ ] 时间暂停 + 决战时刻（完整版，这是验证核心）
- [ ] 视野锥可视化
- [ ] 巡逻 AI（至少 2 条巡逻路线）
- [ ] 2 个角色的差异化技能
- [ ] 快速存读档
- [ ] 尸体搬运 / 藏匿
- [ ] 噪音传播（基础版）
- [ ] 基础关卡场景（1 个区域，可用商城资产）

### MVP 明确不做的系统

- 飞鸟哨探（微创新）
- 高阶敌人 / 气息感知
- 评分系统（MVP 阶段只做"通关/失败"）
- 夜间光照系统（MVP 用日间关卡）
- 多关卡流程 / 菜单 / 存档进度
- 角色解锁系统
- 完整音效音乐（用占位素材）

### MVP 成功标准

| 指标 | 通过标准 |
|------|----------|
| **重试意愿** | 测试者失败后主动想再试一次（不需要你鼓励） |
| **规划快感** | 测试者会说"等一下，让我想想"而不是直接冲 |
| **决战时刻反馈** | 测试者会主动使用决战时刻，而非绕开它 |
| **疲劳度** | 连续 3 次失败后仍不烦躁 |

**如果 MVP 不通过：** 回到本阶段重新审视核心循环，而不是继续加内容。这是 MVP 的全部意义。

## 十四、范围分层

**MVP → 可发布版：**
- +1–2 个角色（差异化技能组合）
- +4–5 个关卡（难度递进）
- + 飞鸟哨探微创新
- + 高阶敌人类型
- + 夜间光照关卡
- + 评分系统
- + 完整音效音乐
- + 菜单 / 存档 / 设置

**可发布版 → 完整愿景：**
- +1 个角色
- +4–8 个关卡
- + 挑战模式 / 速通支持
- + 美术/UI 全面打磨

## 十五、风险评估

| 风险 | 等级 | 缓解措施 |
|------|------|----------|
| **决战时刻系统架构复杂度** | **高** | MVP 阶段优先实现并验证；这是唯一没有成熟 UE 参考方案的系统 |
| **国风美术资产成本** | 中高 | UE 商城免费资产 + 部分自建；风格化处理降低资产精度要求 |
| **RTT 关卡设计工作量** | 中 | 关卡是设计密集型而非代码密集型；MVP 只做 1 关验证产能 |
| **Solo 时间线压力** | 中 | 严格分层，MVP 不通过就不进入下一层 |
| **巡逻 AI 的确定性调试** | 中 | 需要设计师可控的路径系统，UE 原生导航系统需改造 |

### 最大的未解答问题

> **决战时刻在 UE 中的实现，能否达到赏金奇兵3 的手感精度？**

这是唯一可能在 MVP 阶段就宣判项目死刑的问题。建议 MVP 的**第一个实现目标**就是这个系统——如果它做不出来，后面的一切都没有意义。
