## 基础制作包与仓库原有设定的对齐

上传时确认：仓库使用UE 5.6，README描述7人团队，已有决战时刻可行性原型。制作包是此前引擎未确认时写成，原文保留以便追溯；其中“引擎待定”在本仓库落地时更新为UE 5.6，岗位对应现有7人团队。动画归3D负责人协调，音效归队长指定接入者，不假设额外两名专职人员。

以下记录2026-09-21基础方案的对齐关系。首关空间的后续迭代以上方“山寺暗渡”入口为准。
