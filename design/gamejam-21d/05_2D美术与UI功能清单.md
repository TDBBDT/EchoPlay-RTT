# 2D美术与UI功能清单

版本v1.0。P0重点是“玩家看得懂、点得准、能解释失败”。不用先做复杂卷轴框、完整小地图或大量剧情立绘。

## 1. 与3D共用一份角色设定

| 对照项 | 苇音 CHR_A | 岚刃 CHR_B |
|---|---|---|
| 头像关键轮廓 | 侧束短发、短外套领口、机关包肩带 | 窄头部、右肩护肩、收束衣领、腰刀方向 |
| 主色 | 棕褐+苔绿 | 靛蓝+灰褐 |
| UI识别色 | 琥珀黄 #D6A34A | 青蓝 #55A8BB |
| 形状辅助 | 圆点+编号1 | 三角+编号2 |
| 道具形状 | 短竹笛、折叠夹式机关、短匕首 | 石子、三叶飞镖、短刀 |
| 头像构图 | 胸像，面朝画面内侧 | 胸像，面朝画面内侧 |

D2拿3D角色设定草版，D4把2D头像和3D粗模同屏核对，D5锁定外形。头像画成另一套发型或让飞镖从三叶变四角，都需要返修；先做头像草稿，避免早期精画后重做。

不用给每个状态重画一张脸。选中、禁用、警觉、行动中优先由边框、遮罩和小标表达。

## 2. HUD信息布局

以1920×1080画板制作，四边安全边距约24像素，支持1280×720缩放。字号以1080p下正文20—24像素、说明18—20像素为起点；到720p仍需实际检查，不能只按比例缩小到看不清。

```text
┌────────────────────────────────────────────────────┐
│ 当前目标：取得巡防文书                 暂停 / H帮助 │
│ 可收起的教学卡                                      │
│                                                    │
│         世界：视野、声波、角色与守卫                 │
│                 悬停提示跟随目标                    │
│                                                    │
│ [1 苇音] [2 岚刃]  [Q 暗杀] [W 专属] [E 专属]      │
│ 姿态/风险          技能说明/无效原因                 │
└────────────────────────────────────────────────────┘
```

两名角色头像固定在左下；技能栏显示当前所选角色的三格。顶部只放当前主目标，避免同时显示所有后续步骤。教程卡可关闭但H随时重看，不拦住点地面移动。

## 4. 图标辨识规范

技能图标统一斜向光源、低饱和底色和暖白边缘；64×64实际显示时能够从剪影辨认。不要把完整场景插画塞进小图标。

- 暗杀：短刃与背面目标的关系清楚，不和飞镖混用。
- 陷阱：机关开合轮廓突出，不画成手铐或捕兽笼。
- 笛声：短竹笛为主体，声线为辅；不要只有音符。
- 投石：圆钝石头+弧线；强调改变朝向，提示文字写“转头”。
- 飞镖：三叶锋利剪影+直线；库存数字放右下角，不画在贴图里。

明暗对比优先于纹理。统一描边粗细，图标边缘预留10%安全区，缩小后不被技能框切断。

## 5. UI组件的交互状态

### 5.1 角色头像

| 状态 | 表现 | 玩家动作/反馈 |
|---|---|---|
| 未解锁 | 深色遮罩+锁标；仍保留人物剪影 | 悬停“前往会合点”；点击不切人 |
| 可用未选中 | 正常图、较细框 | 点击选中 |
| 选中 | 识别色边框+编号/形状标记 | 与地面选中环同时更新 |
| 动作中 | 小行动标记 | 可切人，但本角色新命令受行动锁限制 |
| 正在暴露 | 黄色风险进度 | 悬停提示“正在被守卫观察” |
| 已确认发现 | 红叹号+危险方向提示 | 可切人；共享失败规则见01 |
| 隐藏/下蹲 | 对应小图标 | 不用绿色头像暗示绝对安全 |

原型没有血量，因此不要设计血条、治疗按钮或死亡后可复活槽位。

### 5.2 技能格

| 状态 | 表现 | 悬停说明 |
|---|---|---|
| 可用 | 正常图、Q/W/E角标 | 名称、作用、射程、声音范围、风险 |
| 瞄准中 | 亮边+“选择目标/确认施放” | 右键取消 |
| 冷却 | 灰色遮罩+数字倒计时 | 显示剩余秒数 |
| 已消耗 | 0/1数字+道具回收小标 | “找回飞镖”或“回收机关” |
| 本动作不可用 | 灰色图+原因 | “先放下尸体”“动作中” |
| 教学未解锁 | 锁标 | “到达前方教学区解锁” |

库存、冷却、姿态、目标有效性是不同概念。角色可以有库存但目标无效；不要把所有失败都显示成“冷却中”。技能禁用原因优先级：未解锁→角色动作锁/拖尸→缺库存→冷却→当前目标无效。

### 5.3 无效操作反馈

光标边缘出现红色短划+具体短文案，0.8秒淡出；不弹阻塞对话框。文案包括：“超出范围”“无法到达”“被障碍挡住”“需要从背后接近”“目标已失效”“先放下尸体”“机关已布置”“先取回飞镖”。

## 6. 页面和功能清单

| 页面 | P0功能 | 美术交付 | 程序接入边界 |
|---|---|---|---|
| 标题页 | 开始游戏、设置、退出 | 简洁背景+标题样式+通用按钮 | 背景可用关卡截图；不放继续游戏 |
| 游戏HUD | 双头像、三技能、目标、提示 | 排版稿+组件 | 绑定动态数据 |
| 暂停页 | 继续、重试本段、设置、回标题 | 遮罩、面板、按钮 | 禁止输入穿透 |
| 设置页 | 主音量/音效/音乐、声音范围显示 | 滑块、开关 | 数值可保存；没有音乐则隐藏音乐滑块 |
| 帮助页 | 已学操作与技能简述 | 键帽和图文排版 | H打开/关闭；暂停游戏，与暂停菜单同一时间规则 |
| 重试确认 | 确认/取消 | 复用通用弹窗 | 写明“将返回本段起点” |
| 失败页 | 原因、重试本段、从头开始、回标题 | 通用底板+失败标题 | 显示看到玩家的敌人方向/名称，避免只有“失败” |
| 胜利页 | 用时、失败次数、确认发现次数、重玩/标题 | 简洁结算排版 | 不新增未实现的评分/成就 |

标题背景优先使用完成后的关卡截图，省下一张大插画的时间。P0无小地图：本关很短，用目标标记与镜头归位足够。

## 7. 世界空间标记

- 敌人问号=调查；叹号=已确认发现；耳朵=刚听见声音。图标出现后不持续跳动，避免巡逻时满屏晃动。
- 视野近区为实填、远区为条纹；只用红绿区分不足以解释蹲伏规则。
- 角色选择环用苇音圆点、岚刃三角，并显示编号；色弱情况下也能区分。
- 文书箱标记只在接近或悬停时突出；主目标方向提示可在屏幕边缘显示，不给所有装饰加轮廓。
- 飞镖掉落和已布置机关用专属小图标，不共用闪亮宝物标记，避免误以为是新增收集品。
- 出口提示两个小人/头像槽，显示谁已到达；满足任务后才亮起“撤离”字样。

## 10. 交付包与验收

每项交：可编辑源文件、透明PNG、色板、字体及来源说明、9切片边距、光标热点、尺寸、状态示意。字体使用能够覆盖简体中文的可用字体，并记录随包分发所需的授权信息。

先交一张HUD总稿和组件拆分，不要只给一张扁平大图；程序需要独立头像、框、图标、遮罩和文字位置。通用组件优先使用引擎已有UI系统实现，美术负责样式。

验收：720p下图标辨识、正文可读；库存数字不被冷却遮罩盖住；文本放大到125%仍不溢出关键按钮；所有按钮有悬停/按下/禁用状态；鼠标点UI不会使角色移动；截图中2D头像与3D人物外形一致；关闭声波显示后仍能读懂警觉状态。
