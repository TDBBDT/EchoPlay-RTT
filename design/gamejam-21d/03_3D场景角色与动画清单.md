# 3D美术制作清单：场景、角色、道具、动画

版本v1.0。先做能进入游戏验证的低精度资源；所有P0先通过比例、碰撞、动作接入，再精修。

## 1. 制作顺序与风格基准

第一批不是整片森林，而是一个“角色+树+石+灌木+道路”的5×5米风格样块。使用正式镜头角度截图审批：轮廓、明暗和材质通过后批量复制风格。

顺序：尺度块→核心掩体→共用角色骨架→三个人形粗模→基础动作→技能道具和动作→井亭/岗哨→自然装饰。场景美术与角色动画可以由不同人并行制作；同一人负责时，优先保证粗模和动作完整。

### 风格要求

- 写实比例为基础，角色手部和武器轮廓略夸张，确保俯视下可识别动作；不做大头Q版。
- 模型轮廓有设计感，岩石用明确大切面，树冠以成组叶团表现；材质有手绘概括感但保留木/石/布的粗糙度区别。
- 主色偏低饱和，角色识别色比环境亮一档；地面纹理避免高频噪点抢过声波和视野。
- 只锁一个清晨光照方案，阴影方向一致；树冠不能让整个玩法区域变成一片暗黑。
- 不直接把原作人物截图当贴图或图标；以00的原创角色轮廓和固定色板完成本项目版本。

## 4. 两名角色设计任务书

### CHR_A 苇音：诱敌与设陷

成年女性，身高参考1.65米，行动轻巧但不是夸张可爱风。短外套和紧束袖口适合下蹲；肩背轮廓偏圆，左侧腰包略大，腰包里放折叠机关；短竹笛固定在胸前或腰前，动作时右手拿起。发型采用侧束短发，避免过长发辫和布条增加物理模拟。

材质：棕褐布、少量苔绿边、旧皮革绑带、哑光铁机关。识别色琥珀黄用于头巾小块、肩带和UI边框，不能全身亮黄。

需要画出的设计页：正/背/侧视；头部近景；短匕首、竹笛、陷阱收拢/展开两态；待机与下蹲剪影；俯视镜头截图。角色设计页由3D角色负责人牵头，2D必须使用同一版。

动作性格：下蹲低、步幅小；设陷时先压低身体再打开机关；吹笛时站起，双手持笛，结束快速收回。不要制作需要全身绳索物理的技能。

### CHR_B 岚刃：精确出手与潜入

成年男性，身高参考1.75米。收束的靛蓝长衣，右肩一块不对称护肩，腰侧短刀，前臂护布。头部轮廓偏窄，发型或头巾形成小三角；不做长披风。

材质：靛蓝布、灰褐皮革、暗金属；青蓝识别色用于肩部系带与刀鞘线条。刀柄、护肩形状必须在头像和技能图标参考页里保留。

需要画出的设计页：正/背/侧视；头部；短刀与三叶飞镖；站立、奔跑、投掷剪影；俯视截图。

动作性格：跑步重心稳定，暗杀迅速；投石与飞镖可共用下半身和起手动作，但投石为抛弧线，飞镖为短促平掷，最终至少保留不同手部姿态。

### CHR_GUARD 普通守卫：必须补进制作计划

一款成年守卫基础模型，三角/窄帽轮廓、深褐灰衣、暗红腰带。武器作为腰间静态配件，原型不需要射击或搏斗动作。7个实例共用模型，可换腰带深浅，不做7个角色。

敌人待机、走路、追近可复用共同骨架动作；转头、疑惑、死亡另补。正面方向必须能从帽檐、胸部和脚尖快速读出。

## 6. 动画制作规范

交付30fps原地动画；表中时长是目标，逻辑时长由程序配置。普通循环首尾连续；非循环不把恢复待机强行烘到很长的尾部。移动由程序导航驱动，走/跑循环不内含前进位移。

共用骨架需要`root / pelvis / spine / head / hand_l / hand_r / foot_l / foot_r`语义对应，不强制软件命名，但提交映射表。预留右手武器、双手笛子、腰部道具、背后拖尸锚点；左右手握点位置记录在源文件。

两名玩家共享共通动作，守卫复用站立、行走和奔跑。各角色只做必要姿态修正，防止重定向后手穿身体或武器悬空。

## 7. 技术预算与交付格式

初始预算：主角每人8k—15k三角面，守卫6k—10k；核心掩体约0.5k—3k；普通小物100—1k。树木总量和透明叶片开销比单件面数更需要实际验证。角色通常使用1套2K贴图，环境优先共享1K/2K图集；这些是预算上限建议，不要求用满。

使用统一PBR通道说明：BaseColor、Normal、Roughness、Metallic、AO；若引擎打包通道，由程序给模板。不要自行默认光滑度与粗糙度互为同一输入。材质名保持稳定，贴图不含绝对本地路径。

每件资源包包含：源文件、导出文件、贴图、正面/俯视预览、尺寸、原点位置、功能碰撞说明、版本号。碰撞用简单盒/胶囊/凸体组合；灌木只做触发体建议，不做阻行走碰撞。

绑定模型必须附：骨架层级、T/A姿势、挂点说明、动画清单、循环标志、关键事件时间。临时骨架确定后，禁止中途改骨名、增删root层或缩放根骨而不做迁移验证。

## 8. 3D与2D的协调关口

1. D2：角色负责人交两名角色的色板、剪影、头部草图、道具草图；2D据此做头像与技能图标草版。
2. D4：把3D粗模和2D头像同时放到游戏HUD截图里，检查发型、肩甲/肩带、衣领、配色是否一致。
3. D5：冻结轮廓、色块和技能道具形状，2D开始精修；之后允许调材质，不随意改发型与武器外形。
4. D10：角色动画带道具录屏交程序与特效，确定挂点、时刻、朝向。若改动技能动作，更新01和04中的同名事件。

## 9. 本工种验收

- 角色在最终镜头最小缩放下仍能看出谁是苇音、谁是岚刃；灰度下也能靠轮廓区分。
- 下蹲、跑步、暗杀、吹笛、放陷阱的轮廓彼此清楚，不靠近景才能理解。
- 共用动画在两名角色身上没有明显脚滑、手穿身体、武器反握或漂浮。
- 井、岩石、树干碰撞与画面接近；可通行缝隙至少允许0.6米直径的角色通过并留余量。
- 树冠淡出不会连树干一起消失，敌人和可拾取道具不会被透明排序吞没。
- 所有P0资源已在02的关卡里实际使用；未使用的新装饰暂停制作。
