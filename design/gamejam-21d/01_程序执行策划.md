# 程序执行策划：从灰盒到首关原型

版本v1.0。固定ID、角色识别和范围见00。所有数值为可调初值，单位米、秒、角度；不要分散硬编码。

## 1. 第一份可玩产出

D1—D3先在一个20×20米测试场实现：选中岚刃→右键移动→C下蹲穿过远视野→绕石头躲近视野→被发现后失败→重新开始。角色用胶囊，敌人用箭头，岩石用方块。

这一版本通过后再做技能和首关。不要先搭完整背包、装备、任务编辑器或复杂战斗框架。

## 2. 输入与选择

不做框选多选，避免组队寻路、队形和批量命令。右键敌人仅提示“按Q准备近身暗杀”，不隐藏执行攻击。UI区域拦截鼠标事件，点击技能按钮不能同时点到地面。

输入优先级：失败/胜利界面 > 暂停菜单 > 技能瞄准 > 情境交互 > 地面移动。角色切换会取消旧角色尚未确认的瞄准，但不取消已下达的移动或技能。

## 3. 移动、姿态与行动锁

| 参数 | 初值 | 说明 |
|---|---:|---|
| 站立行走速度 | 2.2 | P0行走无听觉事件，简化学习成本 |
| 下蹲移动速度 | 1.3 | 无脚步听觉事件，可通过远视野 |
| 奔跑速度 | 4.2 | 每0.45秒发一次半径3米的声音事件 |
| 拖尸速度 | 1.0 | 强制低姿态，不能奔跑或施技能 |
| 角色碰撞半径 | 0.3 | 友方不互相卡死，使用软避让 |
| 情境交互距离 | 0.8 | 角色到交互锚点的平面距离 |
| 寻路终点容差 | 0.15 | 禁止一边抖动一边反复重下命令 |

玩家状态：`Idle / Moving / Aiming / Approaching / Acting / Dragging / Disabled`；姿态独立为`Standing / Crouched`。奔跑是移动模式，不能和拖尸同时成立。

新移动指令替换旧路径。新技能指令可取消Approaching；Acting开始后到结束为短时间行动锁，不接受新移动、姿态和技能指令，显示“动作中”；切人和镜头仍可用。X可取消Approaching，不能取消已提交的暗杀。暂停会冻结动作时间。

寻路失败：不扣库存或冷却，显示“无法到达”，角色留在最后可达位置。路径中断超过1秒仍未恢复时终止指令。玩家角色不与尸体做硬碰撞；静态岩石、井基座、树干和围栏有简化碰撞。

## 4. 视野与暴露：同一套数据同时驱动显示和判定

普通守卫默认视野扇形总角70°，近区0—5米，远区5—10米。每名敌人每0.1秒更新感知；在同一次更新中，所有敌人先读取状态快照，再应用结果，减少顺序差异。

### 4.1 可见性判定顺序

1. 目标必须存活、在距离和扇形内。
2. 从敌人眼部到玩家姿态对应的检测点做遮挡射线；P0用躯干中心一个点，后续可扩为两点。
3. 石头、实墙、粗树干有`SightBlocker`；草、粒子、树叶不凭视觉材质自行阻挡射线。
4. 通过下表判断该姿态/环境是否可见；可见才增加暴露值。

| 玩家状态 | 近区 | 远区 |
|---|---|---|
| 站立/行走/奔跑 | 可见 | 可见 |
| 下蹲且不在灌木 | 可见 | 不可见 |
| 下蹲且在有效灌木内部 | 不可见；贴近例外见下 | 不可见 |
| 站立施放飞镖/投石/吹笛 | 可见；即使原先下蹲 | 可见；即使在灌木中 |
| 下蹲布陷阱/拖尸 | 按下蹲规则 | 按下蹲规则 |

灌木隐藏以角色中心进入`HideVolume`为准；边界做0.15米滞回，防止隐藏状态频繁跳动。敌人距离隐藏玩家≤1.2米且无硬遮挡时可发现，避免贴脸无敌。灌木不能抹除已发生的警觉。

每个敌人对每个玩家独立维护`exposure[characterId]`，范围0—1。持续可见时以近区0.8/秒、远区0.4/秒增加；不可见时0.6/秒衰减。达到1进入Confirmed；低于1属于怀疑，敌人只缓慢朝最后可见位置转头，不额外放大视锥。选中角色的HUD暴露值取所有敌人对该角色的最大值；头顶提示只显示最危险观察者的方向。

Confirmed时，连续保持任一玩家可见3秒则任务失败（抓获）。丢失全部玩家视线立即取消这次连续抓获计时，前往最后已知位置搜索；没有“穿墙全图锁定”。本原型不实现血量与枪械战斗。

近区实填+远区条纹，表示“近区蹲下也危险、远区蹲下可通过”；遇硬遮挡裁剪扇形，禁止可见区域与实际射线判定明显不一致。没有裁剪显示前，用Debug射线验证，不能拿完整扇形当最终表现。

### 4.2 尸体与犯罪目击

可见范围内发现未隐藏尸体，进入调查；尸体不按下蹲/远区规则隐身。每名敌人记录已处理尸体ID，防止同一尸体反复触发循环。

暗杀动作中的双方按站立暴露处理；敌人若看见正在发生的暗杀，直接进入Confirmed，但仍按3秒连续可见条件判负。暗杀开始即令受害者失去感知能力，防止其在被控制动画中继续报警。其他敌人照常感知。

## 5. 听觉事件：范围与声波必须一致

`NoiseEvent = {id, type, sourceId, origin, radius, createdAt, response, priority}`。这是瞬时事件；圆环扩散只是视觉表现。事件发生的当帧就筛选敌人，不能等视觉波纹扫到敌人才听见。

| 声源 | 半径 | 反应 | 优先级 |
|---|---:|---|---:|
| 奔跑脚步 | 3 | 朝最后听见的位置移动调查 | 1 |
| 石子落地 | 3.5 | 原地转头看落点2.5秒，然后恢复原行为 | 1 |
| 近身暗杀/陷阱命中 | 2 | 移动到声源调查 | 2 |
| 飞镖命中 | 3 | 移动到命中点调查 | 2 |
| 苇音笛声 | 8 | 范围内所有可响应敌人前往吹笛当时的位置 | 3 |
| 确认发现后的警报 | 10 | 通知同伴去最后已知位置；不直接让同伴知道玩家实时位置 | 4 |

P0声音按平面距离，不被普通掩体遮挡；场景不放密闭室内，不做材料衰减。教程明确“岩石挡视线，不挡声音”。场景音、音乐和特效播放不自动产生听觉事件。

只有Idle、Patrol、LookAt、Investigate、Search可接受声音；Confirmed忽略诱饵声音。新事件优先级更高则更新目标；相同优先级0.75秒内只接受一次，超时接受最近的新事件。LookAt处理石子时保存原行为，结束恢复；移动调查遇石子也只短暂停步转头，之后继续原调查。

无可达路径的声源：前往距离声源最近的可达点，搜索后返回。多个守卫听见笛声会一起到达；陷阱只处理一个，必须在UI预览中表现“会引来多名敌人”。

## 6. 守卫状态机

| 状态 | 行为 | 退出条件 |
|---|---|---|
| Idle | 在锚点面朝配置方向停留 | 定时进入巡逻/感知到刺激 |
| Patrol | 按路径点行走，点位停留2—4秒 | 声音、尸体、玩家可见、死亡 |
| LookAt | 原地转向石子落点并停留 | 2.5秒后回原行为；更高刺激抢占 |
| Investigate | 走向记录的位置；头顶问号 | 到达→Search；可见玩家→累计暴露 |
| Search | 原地按左/中/右固定节奏扫视，不随机游荡 | 4秒后Return；新刺激更新目标 |
| Return | 回原岗位/最近巡逻点，然后接回路线 | 到点→Idle/Patrol；途中继续感知 |
| Confirmed | 转向可见玩家并以3米/秒追近；广播一次警报 | 连续可见3秒→失败；失去视线→Investigate |
| Dying / Dead | 禁止行动、感知和受重复技能影响 | 动作结束产生尸体；只能被拖动 |

同帧优先级：死亡/受控 > 看见犯罪或暴露满 > 有效玩家观察 > 发现尸体 > 警报/其他声音 > 巡逻。Confirmed广播每次进入只发一次，同源警报ID只接收一次，防止敌人互相广播形成循环。

## 7. 技能详细规则

### 7.1 技能栏

苇音：Q近身暗杀、W陷阱、E吹笛。岚刃：Q近身暗杀、W投石、E飞镖。五种独立图标，其中暗杀共用。

教学解锁表：岚刃Q在B入口解锁，W在B第二安全点解锁，E在E1入口解锁；苇音在C会合时解锁Q/W/E。若玩家绕过推荐安全点，离开B进入C时补齐岚刃Q/W；进入CP_03时补齐全部技能。检查点预设同时保存这些解锁标记，避免重试后技能重新上锁。

共通流程：按键→进入瞄准→显示允许目标、射程、声音范围→左键确认→检查资源/目标/路径→需要靠近的先移动→到达时再次校验→进入行动锁→在配置生效时刻提交结果→恢复原姿态。冷却从生效时刻开始；生效前校验失败不消耗。

瞄准时不暂停。P0仅近身暗杀与交互会自动走到目标旁；投石、飞镖、陷阱必须在当前射程内确认，超出显示“超出范围”，避免角色意外跑出掩体。吹笛以当前角色位置预览，点击地面只确认，不把点击处作为声音源。

布陷阱时临时使用下蹲姿态；动作结束恢复原姿态。吹笛/投掷临时使用站立姿态；逻辑姿态在动作开始时切换，过渡动画包含在对应动作时长内，不另增加技能前摇。技能预览同步显示这一姿态风险。

| 技能ID | 范围/资源 | 动作时长/生效时刻 | 结果与边界 |
|---|---|---|---|
| SK_COMMON_KILL | 到敌背后0.9米内；无限 | 1.2秒 / 0.55秒 | 只对背向玩家的普通守卫；击杀1个；2米声音；不做正面对刀 |
| SK_A_TRAP | 当前角色1米内落点；持有1个 | 放置1.4秒 / 1.0秒 | 平地、可达、非占用区域；接触半径0.45米；只触发首名活敌人；友方无效 |
| SK_A_FLUTE | 角色原地8米圆；无限；冷却6秒 | 1.3秒 / 0.4秒 | 声源固定在生效时的位置；所有可响应敌人调查；角色可在动作结束后离开 |
| SK_B_STONE | 落点6米；无限；冷却3秒 | 0.8秒 / 0.35秒投出 | 弧线飞行0.45秒，落地发3.5米声音；仅转头；普通岩石可越过，关卡边界不可投 |
| SK_B_DART | 敌人6米；库存1个 | 0.9秒 / 0.35秒投出 | 要求无硬遮挡直线；飞行0.2秒；命中普通守卫，3米声音；飞镖留在命中点供岚刃拾回 |

表内动作时长可随动画微调，但逻辑时间和动画事件表必须一起改版。投石与飞镖的冷却/库存从投出提交；听觉在落地/命中发生。

#### 近身暗杀

- 有效方向：玩家相对敌人前向夹角≥120°，即后方120°扇区；准备接近时计算背后锚点，可寻路才接单。
- 到点再次检查距离、角度、目标存活、角色未被行动锁占用。失败显示“目标已转身/目标失效”，停止接近，不自动改为正面战斗。
- 行动开始时锁定双方位置和朝向，并把受害者设为Dying/不可感知；0.55秒确认死亡结果，1.2秒生成稳定尸体状态。其他敌人仍可发现此动作。
- 同一敌人可接受一个执行者预占；第二个攻击者提示“目标已被占用”。预占随取消、失效或读档释放。

#### 陷阱

- 资源状态：`Carried → Armed → Spent → Carried`。放置后技能栏显示“已布置”，世界里显示己方陷阱标记。
- Armed在敌人进入0.45米触发范围时马上锁定一个目标；按距离、再按稳定实体ID排序。目标Dying后停止继续触发；0.35秒完成死亡和声音事件。放置动画及陷阱触发动画见03。
- 右键己方Armed或Spent陷阱，苇音走近0.8米并拾取0.8秒；只允许苇音拾取。拾取提交时复查状态，若同帧有敌人踩中，先处理触发，拾取失败后可再次拾取Spent。
- 不能在尸体、另一陷阱、井基座、出口触发器和不可行走区域重叠布置。普通守卫P0不识破陷阱。

#### 飞镖

- 显示“1/1”或“0/1”；投出之后不因目标随后死亡而自动回到背包。
- 投出前目标死亡/遮挡则取消不消耗；投出后若目标已死，飞镖落在其最后有效位置。P0投出时已校验的飞镖在0.2秒后命中活目标，不再二次被树枝拦截；轨迹表现遵循同一结果。
- 掉落物与尸体分离保存；拖动尸体不会带走飞镖。仅岚刃可右键拾取，耗时0.8秒，拾取后库存恢复。
- 掉落位置若不在导航网格，投射到最近可达点并显示标记；不允许关键资源掉进地图外造成软锁。

#### 投石与吹笛

- 石子只选地面有效落点，不攻击敌人；投石预览标示“转头”，笛声预览标示“调查”。P0不用物理刚体决定最终落点。
- 吹笛、投石和飞镖会临时站起，结束恢复之前的姿态；预览显示“施放时站起”。这是本原型的可读风险规则，3D动画与UI必须配套。

## 8. 拖尸、灌木与任务交互

右键尸体→寻路到0.8米→0.7秒抓取→尸体挂到角色后方拖拽锚点，角色强制下蹲。拖尸中按右键地面移动，X放下耗时0.6秒；技能键和奔跑键提示“先放下尸体”。更换角色不会自动放下。

拖入灌木时尸体仍跟随，不直接销毁。放下后若尸体中心在HideVolume，设置`corpseHidden=true`，停止敌人尸体感知并淡出为低透明轮廓；玩家可按悬停找到并再次拖出。移出灌木后清除此标记。尸体不占导航区域，不会堵路。

两人统一拖尸，不实现一人扛尸、一人拖尸的两套运动；两人可共用抓取、拖行、放下动画。

文书箱：右键靠近0.8米→交互1秒→`hasDocument=true`→更新目标为“双人抵达撤离点”。这是任务布尔值，不做通用背包。文书归小队共享；死亡/失败按检查点重置。

撤离：两人均解锁、存活、位于出口触发区，已取得文书，且无敌人处于Confirmed，持续1秒后胜利。只到一人显示“等待另一名队员”。没有文书显示“先取得巡防文书”。

## 9. 教学、检查点与重试

教学使用显式事件和条件，例如`CharacterSelected`、`EnteredHideVolume`、`SkillResolved`、`DocumentTaken`；不能只靠等待几秒自动判完成。详细触发见02。

P0做4个作者配置的安全检查点：CP_00开场、CP_01会合、CP_02井亭前、CP_03最终岗哨前。它们是预设完整世界状态，不是任意运行时快照。必须在UI写“返回本段起点”，不要写“恢复刚才现场”。

每个检查点配置：已解锁角色、双方出生点/姿态、各敌存活与巡逻节点、已清理区域状态、所有陷阱/飞镖归属、任务变量、教学进度、相机位置。到达安全触发区且无Confirmed时激活；新检查点之前的教学区规范化为已通过，避免把旧尸体问题带入新段。

载入时重建关卡动态对象；清除所有路径、预占、声音事件、粒子、暴露值、临时交互、冷却和抓获计时，再应用配置。投掷物、陷阱库存不重复生成。教学界面随检查点进度恢复。

检查点序号只前进，不倒退；已激活检查点不再次执行规范化。载入出生点即使在触发区内也不重复触发，防止淡入淡出和资源重置循环。CP_01/02/03的即时激活规则与重试预设相同，详见02。

失败界面提供“重试本段 / 从头开始 / 返回标题”。P0不支持退出游戏后继续检查点，标题页必须显示“开始游戏”，不放无效的“继续游戏”。任意时刻快速保存属于P2。

## 10. UI功能与数据绑定

| UI模块 | 显示数据/操作 | 程序责任 |
|---|---|---|
| 双角色头像 | 选中、解锁、行动中、姿态、危险 | 绑定角色状态，不让美术写死文字 |
| 3格技能栏 | 图标、QWE、库存、冷却、禁用原因 | 所有图标状态来自Ability状态 |
| 当前目标 | 会合/穿过岗哨/取文书/撤离 | 关卡状态驱动，最多两行 |
| 教学卡 | 一句解释+一个按键图+关闭 | 关闭不影响玩法进度；H可重看已学内容 |
| 悬停提示 | 对象名、动作、失败原因 | 0.25秒出现，移开立即消失 |
| 世界标识 | 选中环、目标点、尸体/道具、声波、视锥 | 只做显示，不反向决定命中 |
| 警觉反馈 | 问号/叹号、暴露进度、抓获倒计时 | 数字+形状+颜色组合 |
| 暂停/设置 | 返回、重试、音量、声音范围显示开关、回标题 | 暂停冻结AI与技能；声音显示关掉仍保留危险状态提示 |
| 结算 | 通关时间、失败次数、被确认发现次数 | 失败次数跨本段重试累积；从头开始清零 |

计时只统计实际游玩时间，不计暂停/加载/结算；重试保留已经花费的游玩时间。P0不做评级、星级和非致命成就。

## 11. P1：简化双人规划与指定点跳跃

只有D12的P0完整通关验收通过后才进入。若未进入，UI及教程完全隐藏这些功能。

**规划模式**：Space进入并暂停玩法；两人各最多记录1条技能命令，仅接受当前就能执行的有效技能（不自动接近目标）；切人可配置另一条。替换覆盖旧命令，右键取消当前瞄准，Esc退出并清空草稿，Enter验证全部后恢复时间并同时开始。任一指令失效则整组不提交、不消耗，提示原因。同步开始不代表同步命中；教程与关卡不能假定不同动画的命中时间相同。P0正常暂停菜单仍不能下指令。

**跳跃**：只做关卡标记的一对跳点，间距≤1.5米，高差≤0.3米；右键跳点自动走到起跳锚点，播放0.8秒跳跃并沿预设曲线移动。期间禁止其他动作、算站立可见、落地发2米声音，完成后恢复原姿态。落点阻挡时起跳前拒绝；不做空中改向、自由跳跃或悬崖坠落。F区可有一个可绕行的溪沟捷径，删除跳点仍可通关。

## 12. 推荐模块与数据契约

保持小型模块，不做通用框架工程。建议拆为InputRouter、Selection、CharacterMotor、CommandExecutor、AbilitySystem、Perception、GuardFSM、NoiseBus、Interactable、Checkpoint、Tutorial、HUD。

关键配置：`CharacterConfig`（速度/姿态）、`AbilityConfig`（范围/时长/生效/库存/声音）、`GuardConfig`（视野/暴露/路线）、`CheckpointConfig`、`TutorialStep`。引擎资源、JSON或表格均可，由程序选择一种。

统一表现事件：

| 事件 | 至少包含 | 消费者 |
|---|---|---|
| CharacterSelectionChanged | characterId | 头像、选中环、技能栏 |
| AbilityPreviewChanged | abilityId, origin, radius, targetValid, reason | 范围预览、光标 |
| AbilityCommitted | actorId, abilityId, actionId | 动画、技能栏 |
| AbilityResolved | actionId, result, targetId, position | 教学、目标效果 |
| NoiseEmitted | noiseId, type, origin, radius, sourceId | AI、声波特效、调试 |
| GuardStateChanged | guardId, oldState, newState | 状态标记、音效 |
| CorpseHidden | corpseId, volumeId | 反馈、教学 |
| CheckpointActivated | checkpointId | UI提示 |

每个actionId只允许提交一次，防止动画事件重复/低帧跳帧重复扣库存。逻辑根据动作计时提交，动画事件用于对齐表现，提供容错；同一效果不能在逻辑和动画事件中各执行一次。

## 13. 程序验收用例

| ID | 操作 | 通过条件 |
|---|---|---|
| T01 | 两人交替点击移动并切人 | 已行动者不中断；无意外多选；头像一致 |
| T02 | 同一守卫前分别站立/下蹲走过近远区 | 与第4节矩阵一致；岩石后不累计暴露 |
| T03 | 跑步经过距离2.9米与3.1米的敌人 | 前者调查，后者不响应；声波半径对应 |
| T04 | 对岗哨投石、对同一岗哨吹笛 | 投石只转头；吹笛前来；动作结束恢复原姿态 |
| T05 | 笛声覆盖两守卫，路径上只有一个陷阱 | 两人都调查，陷阱只处理首人，第二人可发现尸体 |
| T06 | 暗杀接近时敌人转身/被另一个技能杀死 | 取消且不穿模，不出现重复尸体 |
| T07 | 扔出飞镖，拖走尸体，再拾取飞镖 | 飞镖仍在原掉落点；库存始终最多1 |
| T08 | 把尸体拖入/拖出灌木 | 隐藏标记正确变化；敌人只发现暴露尸体 |
| T09 | 被发现后绕岩石断视线 | 抓获连续计时取消；敌人去最后已知位置 |
| T10 | 同一尸体放在巡逻线上等待三个周期 | 不反复进入无限调查循环 |
| T11 | 施法、投掷中、拖尸中分别暂停并重试 | 无残留对象/计时/粒子；检查点库存与教学正确 |
| T12 | 先绕过敌人或不用推荐技能完成区域 | 主线可继续，不被教学步骤锁死 |
| T13 | 无文书/仅一人/被追踪时进入出口 | 不误判胜利；条件齐备后只结算一次 |
| T14 | 冷却中、UI上、地图外连续点击 | 无穿透输入、负库存、重复动作或报错 |
| T15 | 720p和1080p各完成一遍 | 文字不遮挡按钮，功能信息可读，完整通关 |

调试面板至少提供：显示导航、硬遮挡体、HideVolume、敌人状态、声音圆、暴露值；重置到任一检查点；选择时间速度。调试入口只在开发包启用。
