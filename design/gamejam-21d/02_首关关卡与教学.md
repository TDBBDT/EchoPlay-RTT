# 第一关：林间旧驿道

版本v1.0｜目标时长10—15分钟｜两名角色｜7名普通守卫｜一个文书目标｜四个检查点。

## 1. 关卡目标与节奏

开场：岚刃从森林入口潜入，与苇音会合，利用旧井亭和岗哨间的视线死角取得巡防文书，两人从北侧山路撤离。只用开场两句短字幕交代，不做过场演出。

玩家学到的顺序：移动与镜头→下蹲和视野→投石转头与背后暗杀→切人→陷阱+笛声→拖尸与藏匿→飞镖与回收→双人组合解决岗哨→取物撤离。

整个关卡是一条有少量侧路的路径，不是开放大地图。树与山石遮住未进入区域的远景，危险区域之间留安全口袋，让玩家有时间读提示。

## 2. 灰盒搭建蓝图

设计坐标使用二维平面X/Z，X朝关卡前进方向，Z表示道路两侧。有效区域约114×32米，外围另加不可行走植被带。以下坐标为第一轮灰盒起点，最终按01的视野/听觉参数现场验证再微调。

```text
入口 → A安全林径 → B单哨绕行 → C林间会合/设陷 → D废井藏尸
                                                    ↓
出口 ← F撤离山路 ← E2双哨文书 ← E1飞镖回收练习 ←───┘
```

图示表示教学顺序；实际灰盒按下表X坐标从左向右连续铺设，场景包装可让道路弯折。不要把示意箭头当作额外的空间或传送需求。

| 区域 | 范围X/Z | 玩家进入锚点 | 主要空间关系 |
|---|---|---|---|
| A | X0—18 / Z0—14 | 岚刃(3,4) | 无敌人；弯曲小路、路边石、单株树；镜头与操作安全区 |
| B | X18—36 / Z0—18 | (20,3) | 正路被E01看守；侧边灌木与大岩石形成绕行线；石子落点在敌侧后方 |
| C | X36—56 / Z0—20 | 会合(38,3) | 苇音等待；安全草丛→窄道陷阱位→E02远端岗位 |
| D | X56—74 / Z0—22 | (58,3) | 大岩石与废井形成L形遮挡；E03在内侧、E04外侧巡逻；井旁有藏尸灌木 |
| E1 | X74—86 / Z0—22 | (76,3) | E05守窄路；远程击杀位置、可回收通道、侧边绕路 |
| E2 | X86—102 / Z0—28 | (87,3) | E06与E07分开看守；木屏障和侧路隔断互相观察；文书箱在后侧 |
| F | X102—114 / Z0—20 | (104,6) | 两人撤离区；可选小溪沟捷径，P0有完整步行路线 |

地形P0只用缓坡和同一主要高度层。禁止用高低差制造“看似挡住、射线其实穿过”的关卡题。

## 3. 敌人布置初稿

角度用朝向描述，不规定引擎欧拉角。所有敌人共用01的普通守卫参数。

| ID | 区域/初始点 | 岗位或路线 | 教学用途/约束 |
|---|---|---|---|
| E_01 | B，(29,8) | 固定朝入口方向；站岗停留 | 单敌学习视野、投石、背后接近；附近无其他敌人听到暗杀 |
| E_02 | C，(50,9) | (50,9)↔(51,13)，各停3秒 | 笛声诱敌；与D区敌人保持>8米或在笛声圈外 |
| E_03 | D，(64,8) | 固定朝道路外侧 | 废井内侧可暗杀；尸体若留原处会被E04下一次经过看到 |
| E_04 | D，(69,16) | (69,16)→(70,8)→(68,5)→返回，各停3秒 | 教拖尸；一轮约24—30秒；开局离尸体观察点至少12秒 |
| E_05 | E1，(81,9) | 固定朝横向侧路 | 从掩体边缘可用飞镖；射线可达；尸体周围安全到可以回收 |
| E_06 | E2，(91,11) | 固定朝入口方向 | 被石子转头后可绕行；与E07之间有实木屏障隔视线 |
| E_07 | E2，(97,17) | (97,17)↔(99,13)，各停3秒 | 可被笛声引到侧路；文书箱位于其原岗位后方 |

第一轮必须现场验证：从教学吹笛点到E02≤8米，E03/E04不在圈内；陷阱必须落在E02调查路径上。关键在“真实导航路径经过陷阱”，不是在画面上看起来共线。

最终区E06/E07不要求同时击杀。屏障位置允许分别处理；可以用石子绕过一人、用笛声引开另一人后拿文书。两人初始距离与屏障必须让新手有观察时间。

## 4. 分段教学脚本

### A：安全林径，约1分钟

**布置**：岚刃、地面目标点、两块低石、镜头边界；不放危险敌人。

1. 开场目标“前往林间会合点”。提示“右键地面移动，WASD移动镜头”。
2. 移动超过3米后收起移动卡，提示“按C下蹲；Shift+右键奔跑”。
3. 玩家第一次奔跑出现小声波，说明“奔跑会引起附近守卫注意”。
4. 走到B入口安全石头后触发下一段。

完成条件：进入B安全触发区。玩家没试跑步也允许继续；相应操作保留在H帮助里。不能用“必须点某个像素”锁住流程。

### B：看见视野，再选择行动，约2分钟

**布置**：E01、硬遮挡岩石、远区可通行路径、灌木、背后安全接近点。

1. 进入石头后的安全区，自动突出E01并显示视野4秒，同时提示“悬停守卫查看视野；实心近区会发现蹲伏，条纹远区可蹲行”。此提示不暂停世界。
2. 预设入口在E01视野外，玩家有时间试悬停。
3. 推荐玩家按C穿过远区，或绕岩石前进。
4. 到第二安全口袋后解锁岚刃W投石，提示“石子只让守卫转头；落点会显示受影响范围”。
5. 推荐将石子投向守卫右侧，使其背对通路，再Q选择暗杀；解释“需要从背后接近”。

完成条件：岚刃进入C会合区，E01可以存活。若玩家已经绕过，教学卡改为“你也可以直接避开守卫”，暗杀教程在D补充。不得强制屠杀才能过关。

### C：双角色与陷阱诱敌，约2—3分钟

**布置**：苇音会合点、CP_01、E02、窄路、陷阱推荐位、施笛安全点、施笛后躲藏位。

1. 岚刃到(38,3)附近，苇音解锁；镜头短暂平移到苇音，玩家可立即打断镜头。
2. 目标“让两人通过林间巡哨”。提示“按1选择苇音，按2选择岚刃”。
3. 推荐陷阱点在窄路靠近岩石的一侧，范围圈用点线标明；这里不强制吸附，实际仍遵守1米放置规则。
4. 苇音先到陷阱点旁，W布置；随后回到侧后方吹笛点。吹笛点到E02约6—7米，陷阱位于E02通往声源的路径上。
5. E吹笛，预览标出E02受影响；动作结束后按C/右键进入侧边灌木，避免留在声源原地。
6. 守卫踩中陷阱后提示“机关只能触发一次；右键回收”。
7. 引导岚刃走出会合区，避免忘记第二个角色。

完成条件：两人进入D入口安全区。允许使用近身暗杀或潜行绕过；回收陷阱不作为门锁，但跨检查点时恢复库存。若玩家带着0个陷阱前往下一段，提示“前方检查点会整理装备”。

### D：废井与尸体，约2—3分钟

**布置**：CP_02、井基座、挡视线岩石、E03固定岗、E04巡逻、近旁灌木。

1. 进入时E04远离，让玩家至少有12秒的操作窗口；井和岩石遮住E03与E04之间的视线。
2. 目标“穿过废井岗哨”。提示“尸体会引起调查；右键拖拽，移入灌木后按X放下”。
3. 推荐处理E03，将尸体拖入井侧灌木。井本身只挡路挡视线，不提供扔尸功能。
4. E04回来时若尸体已隐藏，继续原路线；未隐藏则显示问号并调查，玩家仍能逃开重试，不立即判失败。
5. 让玩家等待E04离开或投石转头后通过。

完成条件：两人进入E1。成功隐藏任意尸体时教学卡给一次确认；若两人完全绕行，提示“没有留下尸体，也是一种解法”。

### E1：远程出手与取回资源，约1—2分钟

**布置**：E05、可射击缺口、飞镖标记、回收通道。

1. 首次切回岚刃或到达缺口时解锁E飞镖，提示“只有一枚；使用后需要回收”。
2. 发动前范围显示6米射程和命中处3米声音圈。E06/E07必须在声音范围之外。
3. 命中后在落点显示飞镖图标，技能格显示0/1；右键取回后恢复1/1。

完成条件：两人进入E2前的CP_03。绕行者也可继续。此段不得让飞镖落入水中或不可达地形。

### E2：第一次自由组合，约2—3分钟

**布置**：CP_03、E06/E07、木屏障、两侧灌木、文书箱。

目标“取得巡防文书”。不再逐个给技能按键，只提示“观察两名守卫的分工，用声音改变他们的位置或朝向”。

至少验证三种可行解：

- 稳妥分离：岚刃投石让E06转头→从侧面靠近并处理→苇音在侧路布陷阱、吹笛处理E07→取文书。
- 消耗资源：岚刃在屏障边缘飞镖处理E06→苇音背后处理E07或陷阱诱杀→回收道具→取文书。
- 绕行潜入：一人用石子/笛声分别吸引注意，另一人沿屏障背面接近文书；两人利用巡逻空隙撤离。此解需要现场调位验证，不能仅凭文字认定可行。

P1同步模式如果完成，可增加一条可关闭提示；首关不以同步击杀为完成条件。

### F：撤离，约30秒

文书取得后目标改为“双人抵达山路出口”。地面出口圈显示两个人形位置，角色到达填亮对应位置。只到一人显示头像与“等待苇音/岚刃”。两人满足01的撤离条件后结算。

P1指定跳点可放在这里，作为可绕行捷径。P0沿溪岸石路通行；不能让玩家因为没做跳跃系统而被卡住。

## 5. 检查点配置与规范化

| ID | 激活位置/条件 | 载入时角色 | 载入时敌人 | 装备与教学 |
|---|---|---|---|---|
| CP_00 | 新游戏 | 岚刃在A；苇音未解锁 | E01—E07按初始状态 | 飞镖1；陷阱保留给未解锁苇音；开始教学 |
| CP_01 | 岚刃到C会合点，无Confirmed | 双人在C安全点，均下蹲 | E01规范化移除；E02—E07重设 | 飞镖1、陷阱1；视野/投石已学，进入切人/诱敌教学 |
| CP_02 | 两人进入D安全点，无Confirmed | 双人在D入口安全点，均下蹲 | E01—E02移除；E03—E07重设 | 飞镖1、陷阱1；诱敌已学，进入藏尸教学 |
| CP_03 | 两人进入E2前安全点，无Confirmed | 双人在E2入口，均下蹲 | E01—E05移除；E06—E07重设 | 飞镖1、陷阱1；进入自由组合；文书未取得 |

激活新检查点时同样应用该规范化状态，并用0.3秒淡入淡出遮盖整理；之前区域的守卫移除、装备回满、旧尸体与道具清除。文案显示“到达安全点：已整理装备”。这是比赛原型的明确简化，不暗示真实时间倒流。不要把触发器摆在敌人眼前；双方均在安全区且不被确认发现才触发CP_02/03。

回退旧区域没有新的任务；可以用弯道与轻量单向门隐藏已规范化的区域，但门不制作新交互动画。

## 7. 队长验收：关卡不是摆好就结束

先用灰盒完整跑通，再批准高精度环境制作。每轮至少看：

- 所有P0区域在没有同步模式、没有跳跃时仍可完成。
- 使用默认视野参数时存在安全观察点，玩家不会刚关教学卡就失败。
- 教学笛声只引到预期敌人，最终区才允许多个响应者。
- 陷阱诱导路径能命中；敌人不会自动绕开陷阱碰撞。
- 藏尸区与纯装饰草能区分；井和岩石实际遮挡符合画面。
- 角色被树冠遮住时淡出或显示轮廓；相机移动不会露出未制作的大空洞。
- 两名角色都能走完整条路，边缘路径不把人挤出导航。
- 绕过推荐解法、先杀后教学、装备未回收都不会阻断目标推进。
- 找3名没有参与制作的人试玩，不口头指导；记录首个卡住点、失败点、总时长。超过2人同处卡住，优先修改关卡/反馈，而不是加长说明文字。

体验目标不是让试玩者一次不失败，而是每次失败都能解释“哪个敌人看到了什么”，并在短时间内回到刚才那一小段。
