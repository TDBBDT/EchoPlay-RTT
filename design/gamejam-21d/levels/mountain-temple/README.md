## 流程与空间

![教学流程与主支路](图纸/01_教学流程动线图.png)

| 区域 | 教学与目标 | 敌人数 |
|---|---|---:|
| A 林间接近 | 岚刃观察视野、完成首次背后击杀，发现大门与绕行岔路 | 1 |
| B 崖下绕行 | 藤蔓下降，四块等高巨石之间完成三次水平跳跃，再沿藤蔓上行 | 0 |
| C 山寺庭院 | 背刺独立门卫，换另一处藤蔓攀上石台，推石处理交谈二人，侧门离开 | 3 |
| D 河畔双人区 | 苇音加入，组合诱导、陷阱、搬运、飞镖与牛踢环境杀，取得三封密信 | 8 |
| E 安全缓冲 | 整理情报、确认双人能力与下一目标 | 0 |
| F 终段关隘 | 综合运用双人技能与观察时机，完成中上难度的衔接关卡并共同撤离 | 4 |

![整体空间总图](图纸/02_整体空间总图.png)

全关使用同一套坐标和朝向。崖下跳跃路为 H−3，庭院为 H0，推石台为 H+3；庭院与崖下路线形成上下层关系，桥跨越低处通道。**跳跃只连接同高平台，所有垂直攀升或下降均使用藤蔓。**

![藤蔓与水平跳跃剖面](图纸/04_藤蔓与水平跳跃剖面图.png)

大门暴露段受持续观察，玩家先在安全观察点读懂危险，再沿可见藤蔓进入崖下路径。绕行承担首杀后的节奏放松，同时教会玩家从空间关系寻找替代入口。

## 庭院、双人区与终段

![庭院守卫关系与视线](图纸/03_庭院敌人与视线图.png)

庭院有三个固定教学敌人：独立门卫与交谈组中的一人覆盖正门，交谈组的另一人照应侧门。玩家从藤蔓落点进入独立门卫背后，完成击杀后再攀另一侧藤蔓上推石台，处理交谈组。完整设计稿列出各点位、朝向、遮挡和触发条件。

![双人区敌人巡逻与多种解法](图纸/05_双人区敌人巡逻与解法图.png)

双人区有八名敌人，**D02、D04、D07 携带密信**。其他敌人形成可观察的巡逻与相互照应关系；通过苇音诱导、岚刃处理、掩体等待和环境交互逐步拆解。河边饮水的牛提供环境击杀机会。三封密信是推进目标，清空全区不是唯一解。

![终段敌人与双人动线](图纸/06_终关敌人与双人动线图.png)

终段用四名敌人复用此前能力，强调先观察、再改变守卫关系、最后双人通过。标准解不依赖尚未落地的同步指令系统；同步规划功能的项目级取舍仍依基础制作包执行。
