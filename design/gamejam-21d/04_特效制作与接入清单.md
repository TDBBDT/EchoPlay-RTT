# 特效制作清单：声音反馈、技能、潜行状态与森林氛围

版本v1.0。特效必须帮助玩家判断风险。先完成声音和状态反馈，再制作林雾、落叶等装饰。

## 1. 已布置的两项特效：细化制作要求

### VFX_Noise_Run：玩家奔跑的小范围折射声波｜P0

**用途**：显示玩家奔跑会发出可被守卫听见的声音。只有玩家奔跑产生这一效果；守卫跑步和环境声音不触发同一套玩家声波。

- 形态：脚下贴地的细薄环形折射波，中心透明，向外扩展；边缘有一条很淡的灰白描边，避免只有折射而看不见。
- 初始参数：最大半径3米，单次可见时长0.5秒，每0.45秒一个脉冲；允许短暂重叠，单角色同时最多2个。
- 每个脉冲固定在事件发生的位置，玩家跑开后旧脉冲不跟着移动；贴地高度偏移约0.02米避免闪烁。
- 由程序传入`origin/radius/characterId/noiseId`。以`NoiseEmitted(Run)`触发，不能单独绑在动画脚步上造成AI和画面频率不一致。
- 颜色：主体灰白，源点可带少量角色识别色；不能把整个3米区域染成高亮蓝色。
- 程序与特效共同提供可选的细虚线最大范围圈，让玩家理解最终影响半径；扩散环只负责动感。
- 停止奔跑后不生成新脉冲，旧脉冲自然消失；暂停冻结；重试立刻清空。

验收：地面深浅两种材质上都能看见；不会遮住敌人脚下、陷阱和路径；边界尺寸与程序调试3米圆一致。3米指半径，素材直径必须对应6米。

### VFX_Noise_Flute：苇音吹笛的大范围声波｜P0

**用途**：提示一次吹笛会把范围内能响应的守卫吸引到当前声源位置。

- 预览时：显示以苇音当前位置为中心的8米细虚线圆；范围内能响应的敌人显示小耳朵标记。Confirmed中的敌人不显示“会被诱导”。
- 施放时：0.4秒生效时发出2道错开的贴地环，偏青白、少量柔和亮边，带很轻的折射；视觉总时长1.2秒，最大半径8米。
- 声音源固定在生效时位置。苇音施放后离开，波纹不能跟着角色跑。
- 声波不做爆炸感，不增加屏幕震动，不使周围树木一起摆动。
- 受影响守卫即时出现“听见”反馈并开始调查，不等波纹视觉扩散到其身上。玩法采用瞬时范围事件，扩散是示意。
- 可在笛子附近增加0.3秒极小的空气线条，但不得遮住人物脸与手。

验收：与跑步声波明显有大小和节奏区别；图层叠加时仍能辨认敌人视野；低特效设置中关闭折射后，描边环和范围提示仍能完整表达玩法。

## 2. 本关P0效果总表

“预制体数”不等于全新材质数。所有声波共用一个可调半径/颜色/时长的材质；选择环、范围圆尽量由程序绘制。下表是功能交付项。

| ID | 效果 | 触发/结束 | 初始参数 | 制作负责人/程序接口 | 优先顺序 |
|---|---|---|---|---|---|
| VFX_Noise_Run | 奔跑声波 | Run噪声事件 / 0.5秒 | 半径3米，最多2层/角色 | 特效制作；程序传实际半径 | 1 |
| VFX_Noise_Flute | 笛声波 | Flute噪声事件 / 1.2秒 | 半径8米，2道环 | 特效制作；预览由程序+2D | 1 |
| VFX_Noise_Generic | 石子/暗杀/飞镖/陷阱声音圈 | 对应噪声事件 / 0.45秒 | 半径由事件传入2/3/3.5米 | 复用声波材质，避免新做四套 | 2 |
| VFX_Stone_Impact | 石子落地小尘 | 石子落地 / 0.3秒 | 3—6粒，地面小接触点 | 绑定最终落点；只播一次 | 2 |
| VFX_Dart_Trail | 飞镖短尾迹 | 投出 / 命中或0.2秒 | 细短亮线，不做光球 | 绑定飞镖表现对象，读实际起终点 | 2 |
| VFX_Hit_Small | 暗杀/飞镖/陷阱命中 | 技能结果生效 / 0.2秒 | 1个短闪或2—4个暗红小粒子 | 默认克制；可完全用布尘替代血粒 | 2 |
| VFX_Trap_Snap | 机关触发尘土 | 触发机关 / 0.35秒 | 4—8粒小尘，无大范围烟雾 | 挂机关中心；机关运动由动画负责 | 2 |
| VFX_Interact_Pulse | 拾取/文书取得 | 成功提交交互 / 0.35秒 | 小轮廓脉冲，非持续闪烁 | 2D提供符号；特效表现成功瞬间 | 3 |
| VFX_Hide_Transition | 进入隐藏/藏尸完成 | 隐藏状态变化 / 0.25秒 | 轻淡出+少量叶片可选 | 角色/尸体透明由程序；不用烟雾代替消失 | 3 |

01中的声源半径是唯一数值来源。特效预制体默认值仅供预览，进入游戏后必须接受程序覆盖。

## 3. 状态反馈：划清与2D/程序的分工

| 功能 | 2D交付 | 特效交付 | 程序交付 |
|---|---|---|---|
| 敌人怀疑/发现 | 问号、叹号、耳朵小标 | 出现缩放、短促脉冲；无持续弹跳 | 状态、暴露值、显示时机 |
| 视锥 | 色板/条纹纹理 | 材质建议，不独立算形状 | 扇形、遮挡裁剪、近远区、状态色 |
| 角色选择环 | 圆点/三角识别符号 | 选中时0.15秒轻亮 | 位置、选中角色、缩放 |
| 技能范围 | 边界纹理与有效/无效样式 | 必要材质 | 半径、落点、射程、有效性 |
| 发现方向/抓获倒计时 | 箭头与计时外框 | 可选轻脉冲 | 最危险观察者、剩余时间 |
| 飞镖/陷阱拾取标记 | 专属小图标 | 成功拾取的短闪 | 库存状态、可拾取条件 |

这些项目可以用UI/程序几何实现，不要求特效师把每种HUD组件做成粒子。敌人状态变化的语义由程序负责，特效播放失败不能改变AI。

## 4. 森林与井亭可以添加哪些环境特效

| ID | 效果 | 等级 | 摆放与节制 |
|---|---|---|---|
| VFX_Env_Wind | 草叶/树冠微风 | P1，最优先环境项 | 材质顶点摆动；所有植被共用风向；树干不软成橡皮 |
| VFX_Env_LeafFall | 少量飘落叶片 | P1 | 林冠边缘，每个局部区同时3—8片，别铺满屏幕 |
| VFX_Env_LowMist | 薄地雾 | P1 | 远景和地图边缘；主要战斗路面降低密度 |
| VFX_Env_DustLight | 光束中的灰尘 | P1 | 入口安全区和井亭；相机近处使用少量粒子 |
| VFX_Env_RunDust | 脚步小尘 | P1 | 仅干土地表；与声波分开，尘土没有听觉半径语义 |
| VFX_Env_Stream | 浅溪流动/微波 | P1 | F区；由水材质实现，不制作大型水花系统 |
| VFX_Env_WellDrip | 井边偶发滴水 | P2 | 井作为静态掩体已满足P0；不必须制作 |
| VFX_Env_Butterfly | 小蝴蝶/飞虫 | P2 | 增加噪点且可能像交互标记，可不做 |
| VFX_Env_Fire | 篝火/烟柱 | P2 | 本关无照明潜行和火焰玩法，不优先 |
| VFX_Env_BirdFlock | 惊鸟飞散 | P2 | 会引出声音/警觉预期，本届不加入 |

首选“微风+少量落叶+边缘薄雾”三项就能提升森林氛围，不需要所有环境特效全部开工。

## 5. 统一技术参数

- 参数接口至少支持`worldPosition / radiusMeters / durationSeconds / tint / intensity / qualityLevel`；事件类效果另接`eventId`去重。
- 地面环要贴合缓坡。可用投影/贴花或地面采样，按目标引擎实现；不要把大片横向平面穿进井与岩石。
- 折射依赖最终渲染管线支持。D2与程序确认是否能采样场景颜色；不支持时使用低透明扭曲纹理+描边环的替代方案，声音玩法不依赖真实折射。
- UI范围边界与声波分别设置图层；交互轮廓和危险提示优先于环境粒子。拒绝全屏模糊和大型技能闪光。
- 暂停时特效使用玩法时间冻结；UI按钮过渡可以使用独立UI时间。检查点重置必须清除对象池活跃实例。
- 使用对象池；不在每一步奔跑时反复加载材质或纹理。首轮总量建议：同屏声波≤8，玩法粒子≤150，环境粒子≤200，再根据设备测量调整。
- 提供“标准/低”两档：低档关闭折射、尘埃、落叶和雾，保留范围描边、命中反馈、敌人状态。低档不能降低玩法信息质量。

## 6. 容易漏掉的音效需求

声音不是特效师默认包办，队长要明确一个接入负责人。可以使用团队有权使用的素材或临时音，先保证事件对应。

| SFX ID | 需求 | 等级 | 触发说明 |
|---|---|---|---|
| SFX_Step_Dirt | 土地脚步2—3个变体 | P0 | 动画脚落点播听觉声音；AI噪声按01独立计时 |
| SFX_Flute | 约1秒短笛声 | P0 | 与0.4秒生效点对齐，不另延迟敌人响应 |
| SFX_Stone | 投出/落地 | P0 | 落地音与转头触发同帧 |
| SFX_Dart | 飞镖掷出/轻命中 | P0 | 低响度，玩家仍能听清成功 |
| SFX_Trap | 机关放置/闭合/回收 | P0 | 可用同一机械音变调，闭合最明确 |
| SFX_Kill | 近身暗杀短声 | P0 | 不放夸张长惨叫，以免和2米噪声预期矛盾 |
| SFX_UI | 选中/取消/无效/成功 | P0 | 无效操作音短、低强度，防连续点击刺耳 |
| SFX_Guard | 怀疑/确认提示 | P0 | 无须完整语音；两种短提示区分状态 |
| SFX_Amb_Forest | 轻风与森林底噪 | P1 | 低音量，不盖过技能与危险提示 |

## 7. 交付与验收

每项交付：工程资源/预制体、贴图与材质、参数默认值、事件名、10秒录屏、低画质替代说明。录屏应包含正式镜头，而不是只有近景特效展示。

验收场景一次摆出：浅土地、深草地、岩石边缘、两角色、两敌人。分别验证跑步+吹笛同时发生、视锥叠加、暂停、重试、地图边缘、低画质模式。

通过条件：半径准确；敌人响应时机一致；没有“粒子没到敌人就不应该听见”的误导；关键标记不被粒子盖住；低画质仍可完整通关。
