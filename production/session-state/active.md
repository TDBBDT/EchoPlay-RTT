# 会话状态 — 决战时刻原型

**状态：** Phase 5 — 实现中
**开始日期：** 2026-09-19
**概念：** 江湖暗局 — 决战时刻（Showdown Mode）系统可行性

## 假设

在 UE 5.6 中，玩家暂停时为角色编排「移动 → 击杀」两步指令，恢复时间后指令按序精确执行。

成立条件（需全部满足）：
1. 指令执行无时序漂移（每步动作起始偏差 ≤ 1 帧）
2. 暂停期间敌人 AI、动画、视野检测完全停止
3. 玩家无需引导，60 秒内自主完成一次 2 角色协同击杀
4. 玩家会主动重复使用该机制

## 最大风险假设（优先验证）

UE 的 `CustomTimeDilation` + 自定义指令队列，能否在暂停时完全冻结 AI 感知/动画/寻路，
并在恢复时帧精确按序执行，而不被 Animation Blueprint 与 AI Perception 的时间膨胀副作用干扰。

## 路径

Engine — UE 5.6（C++，无二进制资产）

## 范围

- GameMode 运行时生成全部场景（空关卡即可运行）
- 2 个玩家角色（调试绘制圆柱体，无动画）
- 1 个敌人（巡逻 + 调试绘制视野锥）
- 空格 = 暂停/恢复；鼠标左键 = 排队指令；1/2 = 选择角色；E = 执行；V = 切换视野门控
- HUD 显示指令队列 + 执行时间戳 + 同时性漂移

## 明确砍掉

美术资产 · 材质 · 动画 · 音效 · 菜单 · 存档 · 尸体藏匿 · 噪音传播
飞鸟哨探 · 评分系统 · 角色技能差异化 · 寻路避障
